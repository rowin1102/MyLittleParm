# 🌱 마리팜 (My Little Parm)

## 📌 프로젝트 소개
스마트팜 사용자들을 위한 **커뮤니티 & 관리 플랫폼**입니다.  
회원가입, 이메일 인증, 캘린더, AI 추천 서비스, 자유게시판, 거래게시판, 채팅 기능 등을 제공하여  
**스마트팜 경험을 더 쉽고 즐겁게 만들 수 있는 웹/앱 서비스**입니다.

---

## 🗓 프로젝트 기간
- **2025년 7월 23일 ~ 2025년 8월 27일**

---

## ⚙️ 개발 환경
- **Backend**: Spring Boot, Oracle DB, MyBatis  
- **Frontend**: React, HTML5, CSS3, JavaScript  
- **Libraries & Tools**: Spring Security, SMTP, Toast UI Calendar, Kakao Map API  
- **Version Control & Collaboration**: GitHub, Notion  

---

## 👤 역할 (팀장 – 김영진)
- **프로젝트 총괄**: 전체 일정 관리 및 팀 협업 총괄  
- **로그인/회원가입**: Spring Boot Security를 활용한 인증 및 권한 관리 구현  
- **이메일 인증**: SMTP 기반 메일 전송으로 회원가입/정보 수정 시 이메일 인증 처리  
- **캘린더 기능**: Toast UI Calendar 라이브러리를 적용해 심은 날짜, 성장일, 수확일 관리 기능 개발  

---

## ✨ 주요 기능 (담당 부분)
